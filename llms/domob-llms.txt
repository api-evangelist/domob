## What is actually callable

Domob's public API surface is very small. One operation is documented and live;
everything else is either gated, undocumented, or dead.

- [Media Data API](https://developer.domob.cn/#/doc/api): POST https://developer.domob.cn/developer/api/get/stats — publisher media statistics (requests, bids, impressions, clicks, CPM, media revenue) by day or hour, optionally per ad slot. Document revision 2024-11-01. Verified live 2026-08-12.
- [Domob ADX](https://developer.domob.cn/#/doc/api): adx.domob.cn — ad exchange. Docking document updated 2025-06-13 but hosted on a BlueFocus Feishu wiki behind SSO; adx.domob.cn returns HTTP 401 anonymously. Contract not readable.
- Domob Open API: https://open.domob.cn returns {"page":"Domob Open API"} and structured error envelopes, but publishes no operation list anywhere.
- Reporting API for Publishers v1.0.3: still documented at https://github.com/domob-inc/reporting_api and on Domob's own help centre, but its host dvx.domob.cn is NXDOMAIN. Retired without notice.

## Things an agent must know before calling

- Failure is signalled in the BODY, not the status. Every outcome is HTTP 200; branch on `code` (0 = OK). A client that trusts status codes will read every error as a success.
- The credential is an account password sent in the JSON request body. There is no API key, no token issuance, no scopes and no rotation policy.
- The `Token` header is a signature computed with a key Domob publishes in its own PDF. It authenticates nothing.
- No pagination, no idempotency key, no request id, no rate-limit headers, no timezone on the date fields.
- Revenue figures are explicitly NOT settlement figures — Domob's service agreement makes the stamped statement binding.

## SDKs
